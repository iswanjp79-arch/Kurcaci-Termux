# Protokol 3 Partid - Rem lan Gas Mesin

## PEMICU (Kapan mlaku?)
- Data anyar mlebet
- Deviasi > toleransi
- Perintah manungsa

## TINDAKAN (Apa sing dilakoni?)
- Baca data
- Cek validitas
- Bandingaken baseline
- Hitung deviasi
- Damel laporan

## BATASAN (Apa sing ora pareng?)
- Ora pareng ngowahi data sensor
- Ora pareng nggawe data palsu
- Ora pareng mutusaken tanpa persetujuan
- Ora pareng mlangkahi audit trail
